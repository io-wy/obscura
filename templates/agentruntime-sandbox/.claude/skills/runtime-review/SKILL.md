# Runtime 评审清单

依次检查：

1. **隔离**：宿主机路径、网络出站、capability、凭据和跨沙箱数据访问。
2. **生命周期**：状态转换、重试、超时、幂等删除和部分失败后的清理。
3. **持久化**：快照/模板引用使用持久身份；发布失败的模板不能显示为就绪。
4. **资源归属**：可写卷、临时文件、进程和设备只有一个明确的所有者及回滚路径。
5. **测试**：正常路径、非法输入、超时、重启和清理用例。
6. **运行**：指标、结构化错误、无 Secret 的日志和文档。

只报告可采取行动的发现，按严重程度排序，并附文件/行号和具体后续步骤。
不要因风格偏好阻塞工作。
